# System_info_1
Cкрипт на Python для сбора подробной информации об аппаратном и программном обеспечении компьютера с последующим экспортом данных в структурированный файл формата JSON
Основные возможности:
1. Получение имени узла, версии, выпуска и архитектуры операционной системы
2. Определение количества физических и логических ядер, а также текущей, минимальной и максимальной частоты процессора
3. Фиксация точного времени запуска ОС
4. Сбор данных об общем объеме RAM, количестве используемой и свободной оперативной памяти
5. Перебор доступных дисковых разделов, определение их файловых систем и свободного места
6. Проверка наличия аккумулятора, уровня заряда и статуса подключения к сети

Описание используемых библиотек:
1. psutil (Process and System Utilities).

Тип: Внешняя библиотека.

Это главный инструмент программы. Библиотека отвечает за сбор всей низкоуровневой информации об аппаратной части компьютера и динамических показателях системы:
- psutil.boot_time() — определяет точное время, когда был включен компьютер.
- psutil.cpu_count() — подсчитывает количество ядер процессора.
- psutil.cpu_freq() — опрашивает процессор для получения его текущей, минимальной и максимальной частоты.
- psutil.virtual_memory() — возвращает метрики оперативной памяти (общий объем, занято, свободно, процент нагрузки).
- psutil.disk_partitions() и psutil.disk_usage() — находят подключенные накопители (диски/флешки), определяют их файловую систему и рассчитывают объем занятого и свободного места.
- psutil.sensors_battery() — запрашивает у контроллера питания данные об аккумуляторе (уровень заряда в % и идет ли зарядка в данный момент).

2. platform.

Тип: Встроенный модуль.

Для чего используется в коде: Предназначен для идентификации операционной системы, на которой запущен скрипт. С помощью функции platform.uname() программа получает данные компьютера: название ОС, имя компьютера в сети, архитектуру процессора и точную версию сборки системы.

3. json (JavaScript Object Notation).

Тип: Встроенный модуль.

Для чего используется в коде: Отвечает за финальную обработку данных и их сохранение. Функция json.dump() берет созданный в коде Python-словарь (dict), преобразует его типы данных в международный текстовый формат JSON, выстраивает отступы и записывает всё в текстовый файл с сохранением кодировки UTF-8.

4. datetime.

Тип: Встроенный модуль.

Для чего используется в коде: Используется для работы с датами и временем, так как psutil выдает время запуска компьютера в виде системных секунд (timestamp).
